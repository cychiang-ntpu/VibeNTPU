## 🥉 入門：三峽學餐地圖

**👍 做得好的地方**
- 產品名稱、一句話介紹、三個功能都有，讓人一看就知道在做什麼。
- 有 `charset` 和 `viewport`，中文不會亂碼，手機也能讀。
- 有行動呼籲按鈕（CTA）。

**🌱 可以升級的地方**（試試把這些句子貼給 AI）
- 「請加上一個**痛點**區塊，說明北大學生找吃的時候遇到什麼困擾。」→ 讓人產生共鳴
- 「請把價格改成**免費版 vs 進階版**的比較卡片。」→ 看得出商業模式
- 「請加上**手機版排版**（@media），並讓整體設計更有品牌感。」→ 更像真的產品
- 按鈕目前連到 `#`，點了沒反應：「請讓『立即使用』按鈕捲動到一個加入名單的區塊。」

## 🥈 進階：三峽租屋雷達（首頁版）

**👍 做得好的地方**
- 完整的 Landing Page 結構：導覽列 → 主視覺 → 痛點 → 功能 → 價格 → FAQ → 頁尾。
- 痛點寫得很具體（押金、照片不符、隔音），目標客群會覺得「對！就是我！」
- 價格方案有「最受歡迎」標籤，這是真實 SaaS 常用的行銷技巧。
- 有 `@media` 手機版調整，色彩統一（用 CSS 變數管理主色）。

**🌱 可以升級的地方**
- 「搶先體驗」按鈕還沒有真正收集到任何人的資料 → 這就是第 2 週要做的事！
- 可以加上「使用者推薦」或「已有 N 人加入」的社會認同區塊。

## 🥇 卓越：三峽租屋雷達（MVP 版）

**👍 做得好的地方**
- 串接 **Netlify Forms**（`data-netlify="true"`、`form-name`、防機器人 honeypot），真的能收名單。
- 用 **AJAX（fetch）** 送出，網頁不跳轉，體驗流暢。
- 用 **LocalStorage** 記住會員，重新整理還在，並有「登出」按鈕。
- 送出失敗時有友善的錯誤訊息；表單下方說明資料用途（個資意識 👍）。
- 程式碼有中文註解，發表時能清楚說明每一段在做什麼。

**🌱 還能更好的地方**
- 放上網路後，把網址分享給真實的目標客群，收集**真的**市場數據。
- 下一塊積木：用 [Supabase](https://supabase.com/) 做真正的會員登入系統。

## 👀 怎麼看這些作品？

- **看程式碼**：在 GitHub 上直接點開 `index.html`。
- **看畫面**：用 VS Code clone 整個課程 repo（`https://github.com/cychiang-ntpu/VibeNTPU`），在 `samples/` 裡的 `index.html` 按右鍵 **Show Preview**；或在 GitHub 點開檔案 → 右上角「Download raw file」下載後雙擊。
  > ⚠️ 🥇 卓越作品的表單在電腦上直接打開（`file:///`）時**送出一定會失敗**，因為 Netlify Forms 要部署到 Netlify 後才有作用。
- **用健檢站比較**：把三份檔案丟進 [Vibe 健檢站](../tools/vibe_check.html)，看看徽章亮的差別。

## 🚀 想把 🥇 卓越作品部署起來試玩？

1. 下載 `HIGH/index.html`。
2. 照 [部署教學](../docs/tutorials/github_netlify_deploy.md) 建立新 repo 並部署到 Netlify。
3. 照 [Netlify Forms 教學](../docs/tutorials/netlify_forms.md) 開啟 Form detection 並重新部署。

> 💡 給老師：想直接部署本 repo 的範例，在 Netlify 匯入時把 **Base directory** 設為 `samples/HIGH` 即可。
