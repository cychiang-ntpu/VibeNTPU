🎮 Git 存檔點模擬器

在 VS Code 的「原始檔控制」面板按幾個按鈕，就能把作品存檔、送到 GitHub 總部保險箱，Netlify 美食街攤位就會自動更新！先在這裡玩一次吧 👇

⎇ main
👋 從左邊開始：先按「🤖 請 Copilot 修改」，讓 AI 幫你改網頁。

💻 工作區

你的電腦資料夾，VS Code 打開的地方。改檔案都發生在這裡。

📋 暫存區 Staging

準備要存檔的東西，像把東西放進要寄出的箱子 📦

🗂️ 本機存檔紀錄

Commit 歷史，像遊戲存檔列表。點任一個存檔點可以回去看。

    ☁️ GitHub 遠端

    總部保險箱＋自動傳真機：一收到新存檔，就傳真通知 Netlify。

      🏪 Netlify 網站

      美食街攤位。GitHub 一更新，它就自動重新上架（部署）。

      🚚 收到傳真，部署中…
      🎉 這就是 CI/CD！你沒有碰 Netlify，網站就自己更新了

      ⏪ 回到某個存檔點

      👀 看一眼（checkout）就像遊戲裡「讀取舊存檔偷看一下」，看完還能回到現在。
      ⏪ 還原（revert）不是把後面的存檔刪掉，而是新增一個存檔點，內容跟那一版一樣。歷史不會被刪掉，隨時還能再反悔 👍

      💡 建議順序：🤖 修改 → ➕ Stage → ✅ Commit → ☁️ Sync，然後看最右邊的網站自己變！也試試隊友改 README → ⬇️ Pull，以及點存檔點 ⏪ 還原。

      👈 點一個數字

      🔁 VS Code 按鈕 ↔ 指令

      不用背指令，知道有這回事就好。VS Code 其實就是幫你打這些指令 😉

      VS Code 按鈕背後的指令白話
      Clone 複製存放庫git clone 網址把總部保險箱整個複製一份到你電腦
      ＋ Stage 暫存git add 檔案放進要寄出的箱子
      ✓ Commitgit commit -m "訊息"建立一個存檔點
      🔄 Sync / Pushgit push把存檔送到 GitHub
      ⬇️ Pullgit pull把 GitHub 上的新東西拉下來
      Timeline / 歷史git log看存檔列表
