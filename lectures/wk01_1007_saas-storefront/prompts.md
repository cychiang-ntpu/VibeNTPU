# 第 1 週提示詞

本頁是上課要用的提示詞，複製、替換 `【】` 裡的文字、貼到 Copilot 就能用。不想自己替換的話，可以用 [提示詞產生器](slides/prompt_builder.html) 自動產生。

[← 回第 1 週手把手實作](README.md)

---

## 1. 怎麼把提示詞交給 Copilot（約 3 分鐘）

1. 在 VS Code 確認左側檔案總管最上方是你的 repo 名稱（例如 `RENT-RADAR`）。
2. 按 `Ctrl+Alt+I`（macOS：`⌃⌘I`）打開 Copilot Chat。
3. 在 Chat 輸入框下方的模式選單中選擇 **Agent**。（只想問問題、不想改檔案時選 **Ask**。）
4. 複製下面的提示詞，把 `【】` 裡的文字換成你的內容。
5. 貼到 Chat 輸入框，按 Enter 送出。
6. 如果 Copilot 要求執行終端機指令，選擇 **略過（Skip）**。
7. 等 Copilot 完成後，依第 4 節的清單檢查。
8. 按 **保留（Keep）**。不滿意就按 **復原（Undo）**。

**完成後你應該看到：** 左側檔案總管出現 `index.html`，旁邊有綠色的 **U**。

## 2. 提示詞

### 提示詞 0：題目發想（Ask 模式）

還沒有題目時使用。模式選 **Ask**。

```text
我是一位大學生，正在修習一門創業通識課程。
請提出 5 個以「大學生」為目標客群的 SaaS（以訂閱或免費增值方式營運的網路服務）創業點子。

每個點子請依下列格式說明：
- 產品名稱（簡短、容易記憶）
- 一句話價值主張
- 解決的具體痛點，以及目前使用者如何處理這個問題
- 可能的收費方式（例如免費增值、月訂閱、交易抽成）
- 最大的風險或不確定性

我感興趣的領域是：【例如：租屋、二手交易、飲食、運動、社區活動】
```

### 提示詞 1：產生產品首頁（Agent 模式）

模式選 **Agent**。只要改【產品資訊】裡的 `【】`，其他照抄。

```text
你是一位資深前端工程師兼 UI 設計師，重視行動裝置體驗與無障礙設計。
請在目前工作區的根目錄建立 index.html，作為 SaaS 新創產品的形象首頁（landing page）。

【產品資訊】
- 產品名稱：【例如：三峽租屋雷達】
- 一句話介紹：【例如：北大學生專屬的租屋評價平台，協助同學在簽約前掌握真實資訊】
- 目標使用者：【例如：國立臺北大學的學生】
- 三項核心功能：【例如：1. 租屋評價 2. 契約條款提醒 3. 室友媒合】
- 收費方式：【例如：基本功能免費，進階會員每月 49 元】
- 視覺風格：【例如：清爽、可信賴，主色為青綠色】

【技術限制】
1. 所有 HTML、CSS、JavaScript 寫在同一個 index.html 檔案中，不建立其他檔案。
2. 不使用任何需要安裝或建置的框架（例如 React、Vue），只使用原生 HTML、CSS、JavaScript。
3. 不引用任何外部圖片或外部資源；圖示一律以內嵌 SVG 繪製，不使用 emoji。
4. 支援行動裝置（響應式設計），包含 <meta charset="UTF-8"> 與 viewport 設定。
5. 使用繁體中文，並使用語意化標籤（header、nav、main、section、footer）。

【頁面區塊】
1. 導覽列（產品名稱與選單）
2. 主視覺（標題、副標題、行動呼籲按鈕，例如「加入候補名單」）
3. 痛點說明（目標使用者目前遇到的問題）
4. 功能介紹（三項核心功能，以卡片搭配內嵌 SVG 圖示呈現）
5. 價格方案（免費版與進階版比較）
6. 常見問題
7. 頁尾（版權聲明）

【驗收標準】
- 在 375px 寬度下沒有水平捲軸，導覽列在手機上可正常使用。
- 文字與背景的顏色對比足以清楚閱讀；所有 SVG 圖示有適當的替代說明或標示為裝飾。
- 瀏覽器 Console 沒有錯誤訊息。
- 若包含虛構的使用者回饋或數據，須標示為「示意」。

【輸出要求】
完成後請簡要列出頁面包含的區塊，並說明如何在 VS Code 預覽。
請不要執行任何 git 指令或終端機指令，我會自行使用原始檔控制面板提交。
```

## 3. 現成的修改提示詞

在同一個 Chat 對話中貼上，模式維持 **Agent**。每次只挑一則，改完檢查、按 **保留（Keep）** 後再挑下一則。

**改顏色與風格**

```text
請將 #index.html 的主色調改為【低彩度的藍灰色】，整體風格調整為【沉穩、專業】。只調整顏色相關的 CSS，其他部分維持不變。
```

**新增一個區塊**

```text
請在 #index.html 的功能介紹與價格方案之間，新增「使用者回饋」區塊，放三則示意回饋，並在區塊中明確標示「以下為示意內容」。其他部分維持不變。
```

**修正手機版面**

```text
#index.html 在手機寬度下，【導覽列的選單項目換行並遮住標題】。請修正手機版面，改為可展開的選單按鈕，並確保按鈕可用鍵盤操作。其他部分維持不變。
```

**修改價格方案**

```text
請只修改 #index.html 的價格方案區塊，改為三個方案：免費、學生（每月 49 元）、團體（每月 199 元），並標示最推薦的方案。其他部分維持不變。
```

**畫面有問題時**

```text
我用 Show Preview 開啟 #index.html，觀察到【畫面空白／版面錯亂／按鈕沒有反應】。
請說明可能的原因，並直接修正檔案；修正後請列出你改了哪些地方。
```

小技巧：提示詞中的 `#index.html` 是告訴 Copilot「只改這個檔案」。每改出一個滿意的版本，就可以提交（Commit）一次，當作存檔點。

## 4. 檢查 AI 做的結果

按下 **保留（Keep）** 前後，逐項確認：

- [ ] 被修改的檔案只有 `index.html`，沒有動到其他檔案。
- [ ] 預覽時每個區塊都正常顯示，產品名稱、價格、功能描述都正確。
- [ ] 手機寬度下沒有左右捲動，文字沒有被切掉，按鈕點得到。
- [ ] 虛構的使用者回饋或數字都有標示「示意」。
- [ ] 頁面中沒有任何個人資料、密碼。

課程規定：在學習歷程檔案的「AI 使用紀錄」寫下你用了哪個 AI、做了什麼；提交（Commit）與同步（Sync）要自己操作。完整規範見 [課程計畫](../../docs/course_plan.md)。

## 5. 備案：使用網頁版 AI（約 10 分鐘）

Copilot 額度用完或無法登入時，照下面步驟做，結果一樣。

1. 打開 [提示詞產生器](slides/prompt_builder.html)，在「使用的 AI 助理」選擇 **Claude** 或 **ChatGPT**。
2. 填好欄位，按 **複製提示詞**。
3. 打開網頁版 AI（[Claude](https://claude.ai/)、[ChatGPT](https://chatgpt.com/) 或 [Gemini](https://gemini.google.com/)），貼上並送出。
4. 等 AI 回覆完整的程式碼，按程式碼區塊右上角的 **複製（Copy）**。
5. 回到 VS Code，在左側檔案總管的 repo 名稱旁，按 **新增檔案（New File）** 圖示。
6. 輸入檔名 `index.html`，按 Enter。
7. 在打開的空白檔案中按 `Ctrl+V`（macOS：`⌘V`）貼上。
8. 按 `Ctrl+S`（macOS：`⌘S`）存檔。
9. 依第 4 節檢查後，回到 [第 1 週手把手實作](README.md) 的步驟 17 繼續。

**完成後你應該看到：** 檔案總管中出現 `index.html`，預覽時是完整的網頁。

**如果不一樣：** 網頁只顯示一半 → AI 的回覆被截斷了。請它「提供完整的 index.html，不要省略任何部分」，再重新複製貼上。之後要修改時，也要把目前的 `index.html` 完整貼給網頁版 AI，因為它看不到你的檔案。
