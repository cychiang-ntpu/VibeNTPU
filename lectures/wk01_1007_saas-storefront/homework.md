今天上課時間大多用在安裝軟體和申請帳號，所以有些內容要請你回家完成。這份作業分成三部分：

| 部分 | 內容 | 預估時間 | 期限 |
| --- | --- | --- | --- |
| **A 必做** | 補完課堂沒做完的步驟、讓網站上線、了解架構、修改網頁 | 約 1.5–2 小時 | **10/13（二）晚上前** |

### A2：讓網站上線（約 15 分鐘，課堂上已完成的人跳過）

1. 如果還沒有 Netlify 帳號：照 [課前準備清單](../../docs/tutorials/before_class.md) 步驟 10，用 GitHub 帳號申請。
2. 照 [第 1 週手把手實作](README.md) 步驟 22–25：在 Netlify 匯入 repo、部署、修改網址名稱、用手機打開。

### A3：開啟 GitHub 雙重驗證（約 10 分鐘，課堂上已完成的人跳過）

GitHub 會要求寫程式的帳號開啟雙重驗證（登入時除了密碼，還要輸入手機 App 上的驗證碼）。現在設定好，之後才不會突然被擋在門外。

1. 照 [課前準備清單](../../docs/tutorials/before_class.md) 步驟 1 中的 1-2、1-3、1-4 操作。
2. **一定要保存復原碼**（例如存成檔案放在雲端硬碟，或印出來）。手機遺失時，只能靠復原碼登入。

**完成後你應該看到：** 登出 GitHub 再登入時，會要求輸入手機 App 上的 6 位數驗證碼。

---

### A4：了解架構，完成小測驗（約 30 分鐘）

課堂上老師只示範了一部分，請你自己操作一次。

**步驟 1：把課程教材下載到電腦（約 5 分鐘）**

這一步順便練習 clone。

1. 在 VS Code 上方選單點 **檔案（File）** → **關閉資料夾（Close Folder）**。
2. 點左側 **原始檔控制（Source Control）** 圖示（樹枝分岔的形狀）。
3. 按 **複製存放庫（Clone Repository）**。
4. 在畫面上方出現的輸入框，貼上 `https://github.com/cychiang-ntpu/VibeNTPU` 後按 Enter。
5. 選一個資料夾存放（建議不要和你自己的 repo 放在同一個資料夾裡），按 **選取為存放庫目的地**（Select as Repository Destination）。
6. 右下角出現提示時，按 **開啟（Open）**。

**完成後你應該看到：** VS Code 左側出現 `VibeNTPU` 的檔案，例如 `README.md`、`lectures`、`docs`。

**如果不一樣：** 也可以在瀏覽器打開 <https://github.com/cychiang-ntpu/VibeNTPU>，按綠色 **Code** 按鈕 → **Download ZIP**，下載後解壓縮。

**步驟 2：操作兩個互動網頁（約 20 分鐘）**

1. 在電腦的檔案總管（Mac 為 Finder）中，打開剛剛下載的 `VibeNTPU` 資料夾 → `lectures` → `wk01_1007_saas-storefront` → `slides`。
2. 雙擊 `social_saas.html`，用瀏覽器打開。
3. 照 [第 1 週手把手實作](README.md) 步驟 4、5 操作：點選架構圖上的元件、播放「在 IG 按讚」。
4. 回到 `slides` 資料夾，雙擊 `foodcourt.html`，照步驟 7 操作。
5. 照步驟 8 完成小測驗。

**完成後你應該看到：** 小測驗答對 80% 以上（檢核點 1 完成）。

**步驟 3：閱讀兩份短講義（約 10 分鐘）**

1. [自建或使用雲端服務](saas_architecture.md)
2. [你每天用的 App 背後長怎樣](social_media_architecture.md)

### A5：用 Copilot 修改網頁，練習提交與同步（約 20 分鐘）

這一步會讓你親眼看到：在電腦上改完、按下同步，網站就自動更新。

1. 在 VS Code 上方選單點 **檔案（File）** → **開啟最近使用的項目（Open Recent）**，選**你自己的** repo 資料夾（不是 VibeNTPU）。
2. 照 [第 1 週手把手實作](README.md) 步驟 18：請 Copilot 修改一次網頁，按 **保留（Keep）**。可以直接使用 [提示詞](prompts.md) 中的修改範例。
3. 照步驟 19：用手機寬度檢查版面，有問題就再請 Copilot 修正。
4. 照步驟 20、21：提交（訊息寫清楚改了什麼，例如 `修改主色並加入學長姐推薦`）、同步變更。
5. 等約 1 分鐘，用手機重新整理你的 netlify.app 網址。

**完成後你應該看到：** 手機上的網站變成新的樣子，而你完全沒有到 Netlify 按任何按鈕。

**如果不一樣：** 網站沒更新 → 確認你有按 **同步變更**（只按提交，網站不會更新）；見 [疑難排解手冊](../../docs/tutorials/error_guide.md) Q13。

---

### A6：建立學習歷程檔案，並回報網址（約 15 分鐘）

1. 在 VS Code 打開你 repo 裡的 `README.md`。
2. 打開 [學習歷程檔案範本](../../templates/portfolio_README.md)，全部複製，貼到 `README.md` 取代原本內容。
3. 填入產品名稱與網址，勾選已完成的檢核點，寫下第 1 週反思。
4. 按 `Ctrl+S`（Mac：`⌘S`）存檔。
5. 提交（訊息：`新增學習歷程檔案`）、同步變更。
6. **10/13（二）晚上前**，把你的網站網址貼到課程群組。

**完成後你應該看到：** 在 GitHub 打開你的 repo 首頁，下方顯示你的學習歷程檔案。
