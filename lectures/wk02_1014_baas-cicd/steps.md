## 段落 0｜🔁 暖身

- [ ] 不看筆記，跟隊友回答學習單第 1 題的 3 個問題
- [ ] VS Code → **檔案 → 開啟最近使用的項目** → 打開上週 clone 的 repo 資料夾
- [ ] 原始檔控制面板按一次 **同步變更**（確保跟 GitHub 一致）

## 段落 1｜🧠 資料去哪了？

- [ ] 打開 [data_flow.html](slides/data_flow.html) 分頁①
- [ ] 選「沒有後端」→ 在模擬手機上送出表單 → 資料消失了 ❓
- [ ] 選「有 BaaS」→ 再送一次 → 資料飛進 Netlify 後台 ✅

## 段落 2｜📦 收單

- [ ] 打開 [咒語產生器](../wk01_1007_saas-storefront/slides/prompt_builder.html)，切到 **第 2 週** 模式、AI 選 **Copilot**（或用 [prompts.md 咒語 1](prompts.md#咒語-1加入早鳥候補名單waitlist表單)）
- [ ] Copilot Chat → 模式選 **Agent** → 貼上咒語送出（咒語裡有 `#index.html`，Copilot 會直接改你的檔案）
- [ ] 看完變更按 **Keep**
- [ ] `Ctrl+F`（Mac：`⌘+F`）搜尋 `data-netlify`，找得到 ✅
- [ ] Netlify → 你的專案 → 左側 **Forms** → 按 **Enable form detection** ⚠️ **最多人漏掉！**
- [ ] 原始檔控制 → 訊息 `新增早鳥名單表單` → **✓ 提交** → **同步變更**
- [ ] Netlify → **Deploys**，等最新一筆變成 **Published**
- [ ] 用 Netlify 網址（不是電腦上的檔案！）送出一筆測試資料
- [ ] 網址丟群組，幫 3 位同學填表
- [ ] Netlify → **Forms** → **waitlist**，看到名單 🎉
- [ ] [健檢站](../../tools/vibe_check.html) Level 2 全亮 → 📦 **Q4 過關！**
- [ ] 🔄 **交換駕駛／領航員**

## 段落 3｜💾 記住客人

- [ ] [data_flow.html](slides/data_flow.html) 分頁①：送出後按「🔄 重新整理」和「📱 換一台手機」，看看差別
- [ ] 分頁②：完成「集點卡 vs 登記簿」分類遊戲
- [ ] 在同一個 Copilot 對話貼上 [咒語 2](prompts.md#咒語-2送出後原地變成會員儀表板) → **Keep**
- [ ] 原始檔控制 → 訊息 `新增會員儀表板` → **✓ 提交** → **同步變更**
- [ ] 用手機打開網址 → 填表 → 看到「🎉 歡迎回來，[名字]！」
- [ ] 重新整理，歡迎畫面還在 ✅
- [ ] 按「登出」，回到表單 ✅
- [ ] [健檢站](../../tools/vibe_check.html) Level 3 全亮 → 💾 **Q5 過關！**
- [ ] 🔄 **交換駕駛／領航員**

## 段落 4｜🔄 自動傳真魔法

- [ ] [data_flow.html](slides/data_flow.html) 分頁③：看一次 CI/CD 模擬
- [ ] 在學習單寫下預測：Commit ＋ Sync 後需要進 Netlify 按按鈕嗎？
- [ ] 用手機打開網站，記住現在的樣子
- [ ] 貼 [咒語 3](prompts.md#咒語-3快速改版體驗-cicd) 給 Copilot，做一個明顯的修改 → **Keep**
- [ ] 原始檔控制 → 訊息 `改按鈕顏色` → **✓ 提交** → **同步變更**
- [ ] **不要進 Netlify**，等 30 秒，手機重新整理 🪄 → 🔄 **Q6 過關！**
