# Pickle Charm Shop 提示詞

每一段提示詞都是**用中文告訴 Copilot 你要什麼**，不需要看懂程式。
使用方式：VS Code 打開你的 `pickle-charm-shop` 資料夾 → Copilot 聊天面板 → 模式選 **Agent** → 複製整段貼上 → Enter → 檢視變更後按 **保留（Keep）**。Copilot 要求執行指令時按 **Skip**。

一次只貼一段。每段做完，先照 [實作指南](pickle_charm_lab.md) 的「完成後你應該看到」檢查，再貼下一段。

[回實作指南](pickle_charm_lab.md)

## 第一次對話前：先貼這一段「約定」

這一段只貼一次，之後同一個對話裡 Copilot 都會照這些規則做。

```text
接下來我會請你修改這個皮克敏吊飾商店。請遵守這些規則：
- 直接修改工作區裡的 index.html、script.js、styles.css，不要只在對話裡貼程式碼。
- 保持現在的設計風格，手機上也要好看。
- 不要使用 emoji。
- 不要幫我執行任何指令，也不要執行 git。
- 每次只做我這一段要求的事，其他地方不要動。
```

## 提示詞 2：讓註冊資料送到 Netlify 後台（照抄這一段）

這一段是 Netlify 的「暗號」，照抄就好，不用看懂。

```text
請把「加入會員」的表單接上 Netlify Forms，完全照下面做：
- 表單標籤要有 name="signup"、method="POST"、data-netlify="true"、netlify-honeypot="bot-field"
- 表單裡加一個隱藏欄位：<input type="hidden" name="form-name" value="signup">
- 再加一個隱藏的防機器人欄位：<p hidden><input name="bot-field"></p>
- 姓名欄位的 name 是 "name"，Email 欄位的 name 是 "email"
- 表單要直接寫在 index.html 裡，不要用 JavaScript 產生
- 送出時不要跳到別的頁面，改用 fetch 把表單資料用 POST 送到 "/"，格式用 application/x-www-form-urlencoded
```

**完成後：** 在 `index.html` 按 `Ctrl+F` 找得到 `data-netlify`。

## 提示詞 3：送出後顯示「歡迎回來」

```text
「加入會員」表單送出成功之後：
1. 關掉小視窗。
2. 右上角的「登入」按鈕變成「歡迎回來，〔姓名〕」，旁邊多一個「登出」按鈕。
3. 把姓名和 Email 記在這個瀏覽器裡（用 localStorage），這樣重新整理網頁還是會顯示「歡迎回來」。
4. 按「登出」就忘記這個人，畫面回到原本的「登入」按鈕。
如果送出失敗，在小視窗裡顯示「送出失敗，請確認網路後再試一次」。
顯示姓名時請用安全的方式（textContent），不要把輸入的文字當成網頁程式碼。
```

**完成後：** 提交、同步、部署後，手機上註冊 → 顯示歡迎回來 → 重新整理還在 → 登出會消失。

## 提示詞 4：真正的購物車

```text
把「加入購物車」做成真的購物車：
1. 按「加入購物車」就把那個商品放進購物車；同一個商品再按一次，數量加一。按鈕可以一直按，不要變灰。
2. 右上角購物車旁的數字 = 購物車裡所有商品的數量加總。
3. 按右上角「購物車」時，從畫面右邊滑出一個購物車面板，可以關掉。手機上面板佔整個畫面寬度。
4. 面板裡列出每個商品：名稱、單價、數量（有「＋」「－」按鈕）、小計；最下面顯示總金額。數量減到 0 就從購物車拿掉。
5. 購物車內容記在這個瀏覽器裡（localStorage），重新整理後還在。
三個商品的價格分別是：粉糖皮克敏 390 元、夜空藍皮克敏 420 元、陽光草莓皮克敏 450 元。
```

**完成後：** 預覽時加入兩種商品，數字變 2；打開面板，按「＋」總金額會變。

## 提示詞 5：結帳表單（照抄這一段）

```text
在購物車面板的最下面加一個「填寫收件資料」表單，欄位：收件人姓名、電話、地址（都必填）、備註（選填），和一個「送出訂單」按鈕。
如果已經登入，收件人姓名預設填入會員的名字。
購物車是空的時候，「送出訂單」按鈕不能按，並顯示「購物車是空的」。

請把這個表單接上 Netlify Forms，完全照下面做：
- 表單標籤要有 name="order"、method="POST"、data-netlify="true"、netlify-honeypot="bot-field"
- 表單裡加 <input type="hidden" name="form-name" value="order"> 和 <p hidden><input name="bot-field"></p>
- 欄位的 name 分別是 "name"、"phone"、"address"、"note"
- 另外放三個隱藏欄位：name="items"（送出前自動填入「商品 x 數量」的清單，例如「粉糖皮克敏 x2, 夜空藍皮克敏 x1」）、name="total"（總金額）、name="email"（已登入就填會員的 Email）
- 表單直接寫在 index.html 裡，不要用 JavaScript 產生
- 送出時不要跳頁，改用 fetch 把表單資料用 POST 送到 "/"，格式用 application/x-www-form-urlencoded
```

**完成後：** `Ctrl+F` 找到第二個 `data-netlify`；預覽中填資料按送出（本機會失敗，正常）。

## 出問題時

| 狀況 | 貼給 Copilot 的話 |
| --- | --- |
| 找不到 `data-netlify` | `請檢查「加入會員」和「訂單」兩個表單，確認提示詞裡的 Netlify 設定每一條都有做到，少的補上，其他不動。` |
| 送出後跳到 Netlify 的 Thank you 頁面 | `表單送出時跳到別的頁面了。請改成不跳頁，用 fetch 送出，其他不動。` |
| 畫面壞掉、按鈕沒反應 | 按 `F12`（Mac：`⌥⌘I`）→ Console，複製紅字，貼上並說：`我看到這個錯誤：〔紅字〕，請修好，其他不動。` |
| 數量或總金額算錯 | `購物車算錯了：我〔做了什麼〕，畫面顯示〔什麼〕，應該是〔什麼〕。請修好，其他不動。` |
| Copilot 改到不該改的地方 | 按 **Undo**，再貼：`只做我剛才那一段要求的事，其他地方請不要動。` |

## 提示詞裡那些照抄的設定是什麼？（看不看都可以）

| 那一行 | 一句話 |
| --- | --- |
| `data-netlify="true"`、`name="signup"` | 告訴 Netlify「這個表單的資料請幫我收起來」，後台會多一個叫 signup 的收件匣 |
| 隱藏欄位 `form-name` | 用程式送出時，Netlify 靠它知道是哪個表單 |
| 每個欄位都有 `name` | 沒名字的欄位 Netlify 不會記 |
| `bot-field` | 機器人會亂填隱藏欄位，Netlify 就把它丟掉 |
| 表單直接寫在 HTML | Netlify 只看得到寫死在網頁裡的表單 |
| 用 fetch 送出、不跳頁 | 讓畫面停在原地顯示結果 |
