# 每週教材（lectures/）

[← 回課程首頁](../README.md)

這裡依上課日期放每週的手把手實作教材。上課時打開當週資料夾的 `README.md`，照步驟一步一步做即可。做完每段可以對照 [學習檢核點](../docs/checkpoints.md) 確認進度。

## 1. 課程進度

| 時間 | 做什麼 | 檢核點 | 教材 |
| --- | --- | --- | --- |
| 10/7 前 | 註冊帳號、安裝軟體、做出第一個網頁 | 檢核點 0 | [課前準備](../docs/tutorials/before_class.md) |
| 10/7（三） | 了解架構；用 AI 做首頁；發布上線 | 檢核點 1–3 | [第 1 週](wk01_1007_saas-storefront/README.md) |
| 10/14（三） | 加上表單與會員畫面；自動更新；1 分鐘發表 | 檢核點 4–7 | [第 2 週](wk02_1014_baas-cicd/README.md) |

## 2. 每週資料夾裡有什麼

| 檔案 | 給誰 | 用途 |
| --- | --- | --- |
| `README.md` | 學生 | **手把手實作指南**：上課就照這份做 |
| `steps.md` | 學生 | 一頁式步驟清單，可逐項勾選 |
| `prompts.md` | 學生 | 可以直接複製的提示詞 |
| `worksheet.md` | 學生 | 學習單（不計分） |
| `slides/*.html` | 老師與學生 | 互動教材，用瀏覽器直接打開，不需網路 |
| `slides/outline.md` | 老師 | 課堂大綱與時間分配 |
| `announcement.md` | 老師 | 課前與課後公告 |

第 1 週另有 [社群媒體 SaaS 架構講義](wk01_1007_saas-storefront/social_media_architecture.md)，用圖說明大型服務是怎麼分工的。

想了解背後的原理（選讀，課堂不要求）：見 [深入原理](../docs/deep_dive/README.md)。

## 3. 每次上課的流程

兩週的流程相同：

1. **開場**：老師示範或回顧上週重點。
2. **看懂這一段要做什麼**：用互動教材簡單說明。
3. **動手做**：老師先示範，接著你照 `README.md` 的步驟做，兩人一組互相檢查。
4. **對照架構**：每做完一段，確認剛剛做的是架構中的哪一部分。
5. **收尾**：作品巡禮，更新 [學習歷程檔案](../templates/portfolio_README.md)。

教學設計的依據（給老師）見 [教學設計理據](../docs/learning_design.md)。
