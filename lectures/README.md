| 檔案 | 使用者 | 用途 |
| --- | --- | --- |
| `README.md` | 學生 | 本週講義：學習目標、核心概念、課堂時程、各段落的新概念與架構對應 |

## 3. 每週的課堂結構

兩週採用相同結構。固定的節奏可減少學生理解「這週要做什麼」所需的心力，將注意力集中於新內容。

| 階段 | 內容 | 設計目的 |
| --- | --- | --- |
| 1. 開場 | 第 1 週：教師現場示範由提示詞到網站上線；第 2 週：回顧題重新提取第 1 週概念 | 引起注意；提取練習與間隔 |
| 2. 概念 | 以互動教材說明架構與機制，並以預測—觀察—解釋（POE）檢查理解 | 先建立 Why，再進入 How |
| 3. 實作 | 教師示範 → 引導填寫 → 獨立完成；每段只引入一個新概念；配對程式設計 | 範例效應與逐步撤除；管理認知負荷 |
| 4. 架構對應 | 每段實作後，說明剛完成的操作屬於四個架構元件中的哪一個 | 將程序性操作連結回概念架構 |
| 5. 收尾 | 作品巡禮、出場券、更新 [學習歷程檔案](../templates/portfolio_README.md) | 形成性評量與反思 |

教學設計的完整依據見 [教學設計理據](../docs/learning_design.md)。
