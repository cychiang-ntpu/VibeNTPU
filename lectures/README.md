## 🔁 每週都一樣的節奏

每一週都用同樣的結構，熟悉的節奏能讓你把注意力放在「學新東西」，而不是「搞懂這週要幹嘛」：

1. **開場**：🎬 魔術示範（第 1 週）／🔁 回想上週（第 2 週）
2. **觀念**：🧠 用美食街比喻＋互動教材理解「為什麼」
3. **實作**：👀 我做 → 🤝 我們做 → 🚀 你做，每段只有一個 🆕 新概念
4. **架構呼應**：🏗️ 每個實作後，把操作連回四塊積木
5. **收尾**：🎉 作品巡禮＋🎟️ 出場券＋🎒 冒險護照
