## 3. 每週反思

反思不評文筆，而重視具體程度。請寫出具體的事件、錯誤訊息、嘗試過的方法與結果，而非籠統的感想。

1. **我學到了什麼**：用自己的話說明本週最重要的一個概念（例如 Commit 與 Sync 的差別、SaaS 分層架構），並舉一個例子。
   【】
2. **什麼讓我感到意外**：哪件事與你原本的預期不同？你原本的想法是什麼，後來發現實際情況如何？
   【】
3. **我還不理解什麼**：列出一個仍不清楚的概念或操作，並說明你目前的理解到哪裡為止。
   【】
4. **我如何解決一個問題**：描述一次卡關的經過：發生什麼狀況（可附錯誤訊息）、你推測的原因、嘗試過哪些方法、最後如何解決或向誰求助。
