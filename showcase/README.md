## 1. 登記方式

登記作品牆屬於 [延伸任務（選做）](../docs/checkpoints.md#3-延伸任務選做)。

**方式一（建議）**：於本 repo 開立 [作品牆登記 Issue](https://github.com/cychiang-ntpu/VibeNTPU/issues/new?template=showcase.yml)，填寫表單後送出，由教師審核後加入本頁。

**方式二**：將下列資訊提供給助教代為登記：

```
產品名稱：
一句話介紹：
網址：https://
創辦人（可用暱稱）：
最具代表性的設計或功能：
```

### 1.1 隱私與公開須知

- 作品牆為公開頁面，任何人皆可瀏覽，且 Git 歷史會保留修改紀錄。
- 創辦人欄位可使用暱稱；請勿於作品或登記資料中提供電話、住址、學號等個人資料。
- 如需下架，請開立 Issue 或聯繫教師，將儘速處理。

## 3. 作品巡禮回饋格式

作品巡禮（gallery walk）時，請以下列三句式提供回饋。具體、針對作品而非針對人的回饋，較能協助對方改進（Hattie & Timperley, 2007）。

| 句式 | 目的 | 範例 |
| --- | --- | --- |
| **我喜歡**…… | 指出一個具體優點 | 我喜歡價格方案的比較方式，免費版與付費版的差異一眼就能看出。 |
| **我希望**…… | 提出一個可改善之處 | 我希望行動版的按鈕再大一些，目前在手機上不容易點選。 |
| **如果**…… | 提出一個延伸構想 | 如果加入學長姐的使用心得，可能更能建立信任感。 |

撰寫回饋時請避免空泛評語（例如「很棒」「不好看」），並說明理由。
