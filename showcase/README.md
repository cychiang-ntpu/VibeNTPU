# 作品牆

[← 回課程首頁](../README.md)

這裡收錄同學們做的產品網站，讓大家互相觀摩。作品牆**不排名、不評比**，有沒有登記都不影響成績。

---

## 1. 怎麼登記

登記作品牆是 [延伸任務（選做）](../docs/checkpoints.md)。

**方式一（建議）：** 開立 [作品牆登記 Issue](https://github.com/cychiang-ntpu/VibeNTPU/issues/new?template=showcase.yml)，填完表單後按送出。老師確認後會加到本頁。

**方式二：** 把下面資料交給助教代為登記：

```
產品名稱：
一句話介紹：
網址：https://
創辦人（可用暱稱）：
最想讓大家看的設計或功能：
```

### 1.1 隱私提醒

- 作品牆是公開頁面，任何人都看得到，修改紀錄也會保留。
- 創辦人可以用暱稱。不要提供電話、住址、學號。
- 想下架時，開立 Issue 或聯絡老師。

## 3. 作品巡禮怎麼給回饋

看同學作品時，用下面三句話給回饋。針對作品、說出理由，不要只說「很棒」或「不好看」。

| 句子 | 用途 | 例子 |
| --- | --- | --- |
| **我喜歡**…… | 說一個具體優點 | 我喜歡價格方案的比較，免費版和付費版的差別一眼就看懂。 |
| **我希望**…… | 說一個可以改進的地方 | 我希望手機版的按鈕大一點，現在不太好點。 |
| **如果**…… | 提一個新點子 | 如果加上學長姐的租屋心得，可能更讓人信任。 |
