## 🙋 怎麼登記？（支線任務 🖼️ 作品牆明星）

**方法 A（推薦）**：到本 repo 的 [Issues → New issue → 🖼️ 登記作品牆](https://github.com/cychiang-ntpu/VibeNTPU/issues/new?template=showcase.yml)，填好表單送出，老師會幫你加上來。

**方法 B**：把以下資訊貼到課程群組，由助教代為登記：
```
產品名稱：
一句話介紹：
網址：https://
組員（可用暱稱）：
我最得意的地方：
```

> 🔐 **隱私提醒**：可以用暱稱；請不要在網站上放自己的電話、住址等個資。

## 💬 作品巡禮回饋格式

逛同學網站時，用這三句給回饋（研究顯示具體、友善的回饋最能幫助進步）：

- 💚 **我喜歡**……（具體說出一個優點）
- 💛 **我希望**……（一個可以改進的地方）
- 💜 **如果**……（一個大膽的新點子）

範例：
> 💚 我喜歡你的價格方案寫得很清楚，一看就懂。
> 💛 我希望手機版的按鈕可以再大一點，比較好按。
> 💜 如果可以加上「學長姐推薦」的區塊，一定更有說服力！
