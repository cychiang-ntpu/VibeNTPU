## 1. 準備一台筆電 💻

- Windows / macOS / Chromebook 都可以，只要能開瀏覽器。
- 建議使用 [Google Chrome](https://www.google.com/chrome/) 或 [Microsoft Edge](https://www.microsoft.com/edge)。
- 手機也帶著，第二週要用手機驗收「自動更新」的魔法。
- **不需要安裝任何程式！** 這堂課全部在瀏覽器裡完成。

## 2. 申請 GitHub 帳號（總部保險箱）🗄️

1. 前往 👉 <https://github.com/signup>
2. 填寫 Email、密碼、使用者名稱（Username）。
   - 使用者名稱會出現在網址上，建議用英文＋數字，例如 `amy-ntpu-2026`。
3. 到信箱收驗證碼完成註冊。
4. （選做）若你用學校信箱，可以申請 [GitHub Education 學生方案](https://education.github.com/pack)，有很多免費的開發者福利。

📖 官方說明：[建立 GitHub 帳號（繁體中文）](https://docs.github.com/zh/account-and-profile/how-tos/account-management/creating-an-account-on-github)

> ⚠️ GitHub 現在預設會要求開啟 [雙重驗證（2FA）](https://docs.github.com/zh/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication)。請在手機上準備好驗證 App（例如 Google Authenticator、Microsoft Authenticator），並**保存好復原碼**。

## 3. 申請 Netlify 帳號（美食街攤位）☁️

1. 前往 👉 <https://app.netlify.com/signup>
2. 選擇 **「Sign up with GitHub」**（用 GitHub 登入），這樣之後兩邊會自動連線。
3. 跟著畫面回答幾個簡單問題（用途選 Personal / 學習即可），**不需要綁信用卡**。

📖 方案說明：[Netlify Pricing](https://www.netlify.com/pricing/)（我們只會用到免費方案）

## 4. 準備一個 AI 助理（你的 AI 前端工程師）🤖

以下擇一即可，免費版就夠用：

| AI 助理 | 網址 | 備註 |
| --- | --- | --- |
| Claude | <https://claude.ai/> | 產生的網頁可以直接在右側預覽（Artifacts） |
| ChatGPT | <https://chatgpt.com/> | 可以用 Canvas 功能預覽程式碼 |
| Gemini | <https://gemini.google.com/> | 可以用 Canvas 功能預覽程式碼 |

### ⭐ 你的第一次成功：跟 AI 打招呼

打開你選的 AI 助理，貼上這句話：

```text
你好！我是完全沒寫過程式的大學生。請幫我寫一個顯示「Hello NTPU 👋」的 HTML 網頁，
背景要有漂亮的漸層色，文字置中，而且要可以直接預覽。
```

看到畫面了嗎？🎉 **恭喜，這就是你用 AI 做出的第一個網頁！** 你剛剛已經完成了 Vibe Coding。
（如果 AI 只給你一堆程式碼、沒有畫面也沒關係，上課會教你怎麼把它變成網頁。）

> 🧠 **為什麼要先做這一步？** 心理學研究發現，「親身成功過一次」是建立「我做得到」信心最有效的方法。
