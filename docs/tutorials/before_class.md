## 1. 準備一台筆電 💻

- **Windows 10/11 或 macOS** 的筆電（VS Code 需要安裝程式，Chromebook 和平板不適合）。
- 硬碟至少留 **2 GB** 空間。
- 手機也帶著（充飽電），要用手機驗收你的網站。
- 用學校電腦教室的公用電腦？上課前請先問老師，公用電腦可能每次重開機就會還原。

## 2. 申請 GitHub 帳號 🐙

1. 前往 👉 <https://github.com/signup>
2. 填寫 Email、密碼、使用者名稱（Username）。
   - 使用者名稱會出現在網址上，建議用英文＋數字，例如 `amy-ntpu-2026`。
3. 到信箱收驗證碼完成註冊。
4. GitHub 會要求開啟 [雙重驗證（2FA）](https://docs.github.com/zh/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication)：在手機裝驗證 App（Google Authenticator、Microsoft Authenticator 等），並**保存好復原碼**。
5. 🎓（強烈建議）用學校信箱申請 [GitHub Education 學生方案](https://education.github.com/pack)，通過後可以**免費使用 Copilot Pro**（次數比免費版多）。審核可能要幾天，**請盡早申請**；沒通過也沒關係，免費版就夠上課用。

📖 官方說明：[建立 GitHub 帳號（繁中）](https://docs.github.com/zh/account-and-profile/how-tos/account-management/creating-an-account-on-github)

## 3. 安裝 VS Code、Git，並啟用 Copilot 🧰🤖💾

👉 **照 [VS Code ＋ GitHub Copilot 入門](vscode_copilot_starter.md) 一步一步做**，包含：

- [ ] 安裝 VS Code
- [ ] 安裝 Git，並設定 `user.name`、`user.email`
- [ ] 在 VS Code 登入 GitHub
- [ ] 啟用 GitHub Copilot（免費版即可）
- [ ] 安裝 Live Preview 延伸模組
- [ ] ⭐ **請 Copilot 做出「Hello NTPU」網頁**（你的第一次成功！）

> 🧠 **為什麼要先做 Hello NTPU？** 心理學研究發現，「親身成功過一次」是建立「我做得到」信心最有效的方法。

## 4. 申請 Netlify 帳號 ☁️

1. 前往 👉 <https://app.netlify.com/signup>
2. 選擇 **「Sign up with GitHub」**（用 GitHub 登入），這樣之後兩邊會自動連線。
3. 跟著畫面回答幾個簡單問題（用途選 Personal / 學習即可），**不需要綁信用卡**。

📖 方案說明：[Netlify Pricing](https://www.netlify.com/pricing/)（我們只會用到免費方案）

## 5.（選做）先逛逛兩個互動教材 🎮

- [社群媒體的 SaaS 架構](../../lectures/wk01_1007_saas-storefront/slides/social_saas.html)：你每天滑的 IG，背後長什麼樣子？
- [Git 存檔點模擬器](../../lectures/wk01_1007_saas-storefront/slides/git_flow.html)：先玩一次 Commit 和 Sync。

> 在 GitHub 上點開 `.html` 只會看到程式碼。想看到互動畫面，請把整個課程 repo 抓到電腦：
> - **推薦（順便練習 clone！）**：VS Code → 原始檔控制 → **複製存放庫** → 貼上 `https://github.com/cychiang-ntpu/VibeNTPU` → 選資料夾。之後老師更新講義，你只要按 **同步變更** 就能拿到最新版。
> - 或：GitHub 頁面綠色 **Code** 按鈕 → **Download ZIP**，解壓縮。
>
> 然後在檔案總管雙擊 `.html` 檔，用瀏覽器打開。
