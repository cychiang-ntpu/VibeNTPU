# 操作教學（docs/tutorials/）

這裡是課程的手把手操作教學。每一篇都是一步一步的步驟，照著做就能完成；每一步後面都有「完成後你應該看到」，方便你確認有沒有做對。

## 閱讀順序

請依照下面的順序閱讀。

### 上課前（10/7 之前）

1. [課前準備清單](before_class.md)：申請帳號、安裝軟體、做出第一個網頁（檢核點 0）。
2. [VS Code 與 GitHub Copilot 入門](vscode_copilot_starter.md)：課前準備清單中安裝步驟的詳細版，以及 Copilot 聊天的用法。卡住時再看即可。

### 第 1 週（10/7）

3. [Git 與 GitHub 入門](git_intro.md)：建立 repo、複製到電腦、提交、同步變更（檢核點 2、3）。
4. [GitHub 與 Netlify 部署](github_netlify_deploy.md)：把網頁變成公開網站（檢核點 3）。

### 第 2 週（10/14）

5. [Netlify Forms 表單串接](netlify_forms.md)：讓網站可以收集訪客的 Email（檢核點 4）。
6. [LocalStorage 狀態保存](localstorage.md)：讓網站記住訪客已經加入（檢核點 5）。
7. [持續整合與持續部署](cicd.md)：修改後網站自動更新（檢核點 6）。

### 選做

- [以 GitHub Actions 自動檢核網站](vibe_check_ci.md)：完成檢核點 3 之後，讓 GitHub 自動幫你檢查網頁。

### 回家用的電腦和教室不同時

- [Windows 與 macOS 差異對照](windows_vs_macos.md)：課堂用 Windows 桌機、回家用 Mac 的同學請看；也說明怎麼把課堂成果 clone 回自己的電腦。

### 遇到問題時

- [疑難排解手冊](error_guide.md)：Q1–Q18 常見問題與解法。

## 使用提醒

1. **一次做一步。** 每一步做完，先對照「完成後你應該看到」，再往下做。
2. **畫面可能和文件不同。** VS Code、GitHub、Netlify 會改版。按鈕名稱不一樣時，找意思相近的按鈕；仍找不到就求助。
3. **卡住 15 分鐘就求助。** 先查 [疑難排解手冊](error_guide.md)，再問同學、助教或教師，並說明你做到第幾步、看到什麼畫面。
4. **想知道原理再看選讀。** 每篇教學都只放必要的說明；背後的原理放在 [選讀資料夾](../deep_dive/README.md)，課堂不要求。
