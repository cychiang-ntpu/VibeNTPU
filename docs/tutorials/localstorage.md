# LocalStorage 步驟教學：查看與清除瀏覽器裡的資料

[回第 2 週手把手實作](../../lectures/wk02_1014_baas-cicd/README.md)

LocalStorage（本機儲存）是瀏覽器在這台裝置上替網站保留的一個小筆記本。第 2 週的會員歡迎畫面，就是把訪客的名字寫在這個筆記本裡，所以重新整理後網站還記得他。它只存在這台裝置、這個瀏覽器；換手機或清除瀏覽資料就沒有了。因此它只適合存「遺失了也沒關係」的東西，像名字、深色模式，不可以存密碼或 Email。本頁教你用開發者工具看到它、清除它。

想了解原理：見 [表單、儲存與 CI/CD 深入閱讀](../deep_dive/forms_storage_cicd.md)（選讀）。

---

## 步驟 1：先存一筆資料（約 2 分鐘）

先用 [第 2 週提示詞 2](../../lectures/wk02_1014_baas-cicd/prompts.md) 完成會員畫面，並提交、同步。

1. 用電腦的 Chrome 或 Edge 打開你的 `https://…netlify.app` 網址。
2. 填寫表單並送出。

**完成後你應該看到：** 「歡迎回來，〔你的名字〕」。

**如果不一樣：** 沒有出現歡迎畫面 → 見 [疑難排解手冊](error_guide.md) Q17–Q18。

## 步驟 2：打開開發者工具看 LocalStorage（約 3 分鐘）

開發者工具＝瀏覽器內建、用來查看網頁內部狀況的工具。

1. 在網頁上按 `F12`（Mac：`⌘⌥I`）。
2. 在開發者工具上方的分頁列，點選 **Application**（應用程式）。看不到時，按分頁列最右邊的 `>>` 找。
3. 在左側清單找到 **Storage** 底下的 **Local storage**，點一下左邊的小箭頭展開。
4. 點選你的網址。

**完成後你應該看到：** 右側表格有一列資料，**Key**（名稱）是 Copilot 取的名字，**Value**（內容）是你剛剛輸入的姓名。

**如果不一樣：** 表格是空的 → 確認你點的是 netlify.app 網址那一項，而不是其他網址；用 `file:///` 開啟的檔案和 netlify.app 網址各有各的筆記本，互相看不到。

## 步驟 3：確認只存了名字（約 1 分鐘）

1. 看一遍表格中每一列的 **Value**。

**完成後你應該看到：** 只有名字，沒有 Email。

**如果不一樣：** 看到 Email → 在 Copilot Chat 輸入：`請修改 #index.html，localStorage 只存姓名，不要存 Email`，再提交、同步。

## 步驟 4：清除資料（約 2 分鐘）

方法一：用網站上的按鈕

1. 在網頁上按 **登出**。
2. 回到開發者工具，在 Local storage 畫面上方按重新整理圖示。

**完成後你應該看到：** 那一列資料消失，網頁回到表單。

方法二：在開發者工具手動刪除

1. 在表格中點選那一列。
2. 按鍵盤的 `Delete`。也可以在左側網址上按右鍵，選 **Clear**，一次清空。
3. 重新整理網頁。

**完成後你應該看到：** 網頁回到表單，因為網站已經「忘記」你了。

## 步驟 5（選做）：證明這不是真正的登入（約 2 分鐘）

1. 在 Local storage 表格空白列雙擊。
2. **Key** 輸入和原本相同的名稱，**Value** 輸入任何名字，例如 `測試`。
3. 重新整理網頁。

**完成後你應該看到：** 不用填表，畫面就顯示「歡迎回來，測試」。這說明任何人都能自己寫入名字「登入」，所以這只是展示用的模擬登入。真正的會員系統需要伺服器確認身分。

## 記住這三件事

- 只存在這台裝置、這個瀏覽器，換裝置或清除瀏覽資料就沒有了。
- 使用者自己看得到、改得到，所以不能拿來判斷權限。
- 不要存密碼、Email、身分證字號等個人資料。

官方說明：[Chrome DevTools：查看與編輯 Local Storage](https://developer.chrome.com/docs/devtools/storage/localstorage)
