# 延伸學習資源

課堂只有兩次、共四小時。這份清單整理課後可以繼續看的資料，分成兩部分：

- **入門（建議）**：不需要背景知識，看得懂中文或簡單英文就能讀。有興趣的同學建議從這裡開始。
- **進階（選讀）**：專業文件、長文或論文，課堂不要求，適合想往相關領域發展的同學。

[← 回課程首頁](../README.md)　｜　[名詞解釋](glossary.md)　｜　[選讀資料夾](deep_dive/README.md)

**只有一小時的話**，建議依序看：[The Lean Startup：核心原則](https://theleanstartup.com/principles)、[社群媒體的 SaaS 架構（本課講義）](../lectures/wk01_1007_saas-storefront/social_media_architecture.md)、[Vibe coding（Wikipedia）](https://en.wikipedia.org/wiki/Vibe_coding)。
