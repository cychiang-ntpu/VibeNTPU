## 🎯 教學核心理念

> **先教 Why（為什麼要這樣做），再教 How（怎麼做）。**

每個實作步驟完成時，都要回到「美食街比喻」做一次 **🏗️ 架構呼應**，讓學生知道自己剛剛組裝了哪一塊積木。操作是手段，架構觀才是學生帶得走的能力。

## 📅 課前一週

- [ ] 在課程群組公告 [課前準備清單](00-before-class.md)，要求學生**上課前**完成 GitHub、Netlify 帳號申請（課堂上同時大量註冊容易被 GitHub 風控或收不到驗證信）。
- [ ] 老師自己用一個全新帳號從頭走一遍，確認 GitHub／Netlify 介面沒有大改版；若有，更新 [部署教學](../week1/deploy-github-netlify.md) 的按鈕名稱。
- [ ] 把 [examples/week2-waitlist](../examples/week2-waitlist/index.html) 部署成老師的 Demo 網站，第二週上課時現場展示後台名單。
- [ ] 確認教室 Wi-Fi 能連上 github.com、netlify.app、AI 助理網站。
- [ ] 準備一個「救援用」的 `index.html`（可直接用 [examples/week1-landing](../examples/week1-landing/index.html)），給 AI 帳號出問題的學生使用。

| 時間 | 內容 | 老師重點 |

**🗣️ 關鍵台詞**：

- LocalStorage：「這雖然是前端的視覺魔法，換台電腦就不見了。但在 Demo 時，這樣就足以讓投資人完整體驗你的服務流程！」
- CI/CD：「這就是為什麼 IG、Netflix 每天都在更新，你卻不會遇到維修中。」

## ⚠️ 常見卡關點（依發生頻率排序）

1. 檔名變成 `index.html.txt` → 教學生開啟「顯示副檔名」。
2. Netlify Forms 沒開 Form detection，或開了沒重新部署。
3. 用 Netlify Drop 部署（沒串 GitHub），第二週 CI/CD 無效 → 請學生重新 Import from Git。
4. AI 用 JavaScript 動態產生表單，Netlify 掃描不到 → 請 AI 把 `<form>` 寫死在 HTML。
5. 在 `file:///` 本機開啟測試表單，資料當然收不到。
6. GitHub 2FA 設定卡住 → 課前務必完成。

完整排除步驟見 [FAQ](faq.md)。

## 📝 評量建議

| 項目 | 比重 | 評分依據 |
| --- | --- | --- |
| 第一週成果 | 20% | 網站成功上線、有 RWD、內容符合創業題目 |
| 第二週成果 | 30% | Netlify Forms 可收件、LocalStorage 會員畫面、CI/CD 更新紀錄（看 GitHub Commits） |
| 市場驗證 | 20% | 真實目標客群（非同學）的早鳥名單數量與分析 |
| 期末 Pitch | 30% | 能清楚說明 SaaS 架構與商業模式（參考 [Pitch 模板](pitch-template.md)） |

## 🔐 提醒學生的倫理議題

- 收集他人 Email 時要說明用途，發表時截圖要遮蔽個資。
- Demo 用虛構數據沒關係，但正式對外請勿誤導使用者。
- AI 產生的程式碼仍需自己理解與負責。
