# 📖 名詞小辭典

> 期末 Pitch 時用得上的專業術語，都有「美食街比喻」幫你記。

[← 回課程首頁](../README.md)

| 名詞 | 全名／中文 | 美食街比喻 | 一句話解釋 | 延伸閱讀 |
| --- | --- | --- | --- | --- |
| **SaaS** | Software as a Service／軟體即服務 | 在美食街開店，而非深山蓋餐廳 | 軟體放在雲端，用戶透過瀏覽器訂閱使用 | [Azure：什麼是 SaaS](https://azure.microsoft.com/zh-tw/resources/cloud-computing-dictionary/what-is-saas) |
| **PaaS** | Platform as a Service／平台即服務 | 百貨公司提供的水電、廚房設備 | 提供執行程式的平台，你只管寫程式（Netlify 就偏向這類） | [Red Hat：IaaS vs PaaS vs SaaS](https://www.redhat.com/zh/topics/cloud-computing/iaas-vs-paas-vs-saas) |
| **IaaS** | Infrastructure as a Service／基礎設施即服務 | 租一塊空地，自己蓋 | 租用虛擬主機，其他全部自己來（如 GCP、AWS 的虛擬機） | 同上 |
| **BaaS** | Backend as a Service／後端即服務 | 訂單代收中心 | 租用現成的後端功能（資料庫、表單、登入），不用自己寫 | [Backend as a service（維基百科）](https://en.wikipedia.org/wiki/Backend_as_a_service) |
| **前端** | Frontend | 裝潢、菜單、點餐櫃檯 | 使用者看得到、能互動的畫面 | [MDN：網頁入門](https://developer.mozilla.org/zh-TW/docs/Learn_web_development/Getting_started/Your_first_website) |
| **後端** | Backend | 廚房與倉庫 | 處理資料、商業邏輯，使用者看不到的部分 | [MDN：伺服器端程式設計](https://developer.mozilla.org/zh-TW/docs/Learn_web_development/Extensions/Server-side/First_steps/Introduction) |
| **HTML** | HyperText Markup Language | 房子的骨架 | 定義網頁上「有哪些東西」 | [MDN：HTML](https://developer.mozilla.org/zh-TW/docs/Web/HTML) |
| **CSS** | Cascading Style Sheets | 裝潢與油漆 | 定義網頁「長什麼樣子」 | [MDN：CSS](https://developer.mozilla.org/zh-TW/docs/Web/CSS) |
| **JavaScript** | JS | 服務生的動作 | 定義網頁「會做什麼事」 | [MDN：JavaScript](https://developer.mozilla.org/zh-TW/docs/Web/JavaScript) |
| **Git / GitHub** | 版本控制系統／平台 | 總部保險箱＋自動傳真機 | 記錄程式碼每一次修改，並能與其他服務串接 | [GitHub Docs](https://docs.github.com/zh) |
| **Repository（repo）** | 儲存庫 | 一個專案的保險箱 | 存放一個專案所有檔案與歷史的地方 | [關於儲存庫](https://docs.github.com/zh/repositories/creating-and-managing-repositories/about-repositories) |
| **Commit** | 提交 | 存檔點 | 一次修改的紀錄，可以隨時回到這個版本 | [Git 官方書](https://git-scm.com/book/zh-tw/v2) |
| **部署** | Deploy | 開店營業 | 把程式放上伺服器，讓大家都能用 | [Netlify Docs](https://docs.netlify.com/) |
| **CI/CD** | 持續整合／持續部署 | 設計圖一改，分店自動換裝潢 | 程式一更新，就自動檢查並上線 | [Red Hat：什麼是 CI/CD](https://www.redhat.com/zh/topics/devops/what-is-ci-cd) |
| **LocalStorage** | 本地儲存 | 帶回家的集點卡 | 存在使用者瀏覽器裡的小資料 | [MDN：localStorage](https://developer.mozilla.org/zh-TW/docs/Web/API/Window/localStorage) |
| **無伺服器** | Serverless | 不用自己顧機房 | 不必管理伺服器，由雲端平台自動處理 | [Cloudflare：什麼是無伺服器](https://www.cloudflare.com/zh-tw/learning/serverless/what-is-serverless/) |
| **RWD** | Responsive Web Design／響應式設計 | 可以變形的桌椅 | 網頁自動適應手機、平板、電腦螢幕 | [MDN：響應式設計（英文）](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design) |
| **Landing Page** | 形象首頁／登陸頁 | 店門口的招牌與櫥窗 | 介紹產品、吸引用戶行動的單一頁面 | [Unbounce：What is a landing page](https://unbounce.com/landing-page-articles/what-is-a-landing-page/) |
| **CTA** | Call to Action／行動呼籲 | 「歡迎光臨，請點餐！」 | 引導用戶行動的按鈕，例如「立即加入」 | — |
| **Waitlist** | 候補名單 | 開幕前的排隊預約 | 產品上線前收集有興趣的用戶 | — |
| **MVP** | Minimum Viable Product／最小可行產品 | 先擺個試吃攤 | 用最少成本做出能驗證市場的產品 | [Lean Startup 原則](https://theleanstartup.com/principles) |
| **Lean Startup** | 精實創業 | 先試吃再開店 | 建造→測量→學習，快速驗證假設 | 同上 |
| **MRR** | Monthly Recurring Revenue／月經常性收入 | 每月固定的會員費 | SaaS 最重要的營收指標 | [Stripe：什麼是 MRR](https://stripe.com/resources/more/what-is-monthly-recurring-revenue) |
| **Vibe Coding** | 氛圍程式設計 | 跟主廚說「我要清爽的感覺」 | 用自然語言描述需求，讓 AI 寫程式 | [維基百科](https://en.wikipedia.org/wiki/Vibe_coding) |
| **Prompt** | 提示詞（咒語） | 點餐單 | 你給 AI 的指令 | [Anthropic 提示工程](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview) |
