# 🪄 第一週 AI 咒語集：詠唱你的 SaaS 產品前端

> 使用方式：複製咒語 → 把 `【】` 裡的內容換成你自己的 → 貼給 AI 助理（[Claude](https://claude.ai/)／[ChatGPT](https://chatgpt.com/)／[Gemini](https://gemini.google.com/)）。

## 💡 好咒語的三個秘訣

1. **給角色**：「你是一位資深前端工程師」→ AI 會用更專業的標準做事。
2. **給情境**：說清楚你的產品是什麼、給誰用、想要什麼感覺。
3. **給限制**：「只要一個檔案」、「不要用外部圖片」→ 避免 AI 產生你無法處理的東西。

📖 延伸閱讀：[Anthropic 提示工程指南](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview)｜[OpenAI 提示工程指南](https://platform.openai.com/docs/guides/prompt-engineering)｜[Google Gemini 提示詞撰寫技巧](https://ai.google.dev/gemini-api/docs/prompting-strategies)

## 咒語 0：腦力激盪創業題目

```text
我是一位大學生，正在修一門創業通識課。
請幫我發想 5 個適合「大學生」作為目標客群的 SaaS（訂閱制網路服務）創業點子。

每個點子請用以下格式說明：
- 產品名稱（要好記、有梗）
- 一句話介紹（像電梯簡報）
- 解決什麼痛點
- 可能的收費方式（例如：免費＋進階付費、月訂閱）

我的興趣是：【例如：美食、寵物、運動、占卜、租屋、二手交易】
```

## 咒語 1：產生 SaaS 形象首頁（核心咒語）

```text
你是一位資深的前端工程師兼 UI 設計師。
請幫我製作一個 SaaS 新創產品的「形象首頁（Landing Page）」。

【產品資訊】
- 產品名稱：【例如：三峽租屋雷達】
- 一句話介紹：【例如：北大學生專屬的真實租屋評價平台，避開雷房東】
- 目標客群：【例如：國立臺北大學的學生】
- 三個核心功能：【例如：1. 真實評價 2. 房東紅黑榜 3. 找室友媒合】
- 收費方式：【例如：基本免費，進階會員每月 49 元】
- 想要的風格：【例如：清新、活潑、年輕、有信任感，主色調是青綠色】

【技術要求（很重要）】
1. 所有 HTML、CSS、JavaScript 都寫在「同一個 index.html 檔案」裡。
2. 不要使用任何需要安裝的框架（例如 React、Vue），使用純 HTML/CSS/JS。
3. 不要引用外部圖片檔，圖示請使用 Emoji 或內嵌 SVG。
4. 必須支援手機版（RWD 響應式設計）。
5. 使用繁體中文。

【頁面需要包含的區塊】
1. 導覽列（Logo + 選單）
2. 主視覺（大標題、副標題、行動呼籲按鈕 CTA，例如「搶先體驗」）
3. 痛點區（目標客群現在遇到什麼困擾）
4. 功能介紹（三個核心功能，用卡片呈現）
5. 價格方案（免費版 vs. 進階版）
6. 常見問題 FAQ
7. 頁尾（版權宣告）

請直接給我完整的程式碼。
```

> 🏗️ **架構呼應**：AI 產出的這個檔案，就是 SaaS 架構中的 **前端（Frontend）**，也就是你這家雲端餐廳的 **裝潢與門面**。

## 咒語 2：改到你滿意為止

AI 第一次產出的結果通常不會完美，這很正常！Vibe Coding 的精髓就是「**看結果 → 給回饋 → 再修改**」。以下是常用的修改咒語：

```text
請把主色調改成【莫蘭迪藍】，整體感覺更【沉穩專業】。
```

```text
請在主視覺區加上一個簡單的動畫效果，例如標題淡入。
```

```text
請在功能介紹和價格方案之間，新增一個「使用者推薦」區塊，放 3 則虛構的學生好評。
```

```text
手機版的導覽列跑版了，請改成手機上顯示「漢堡選單」。
```

```text
請保持其他部分不變，只修改【價格方案】區塊，改成三個方案：免費、學生 49 元、團體 199 元。
```

> 💡 **小技巧**：修改時加一句「**其他部分保持不變，請給我完整的程式碼**」，可以避免 AI 只給你片段、或是把你滿意的地方也改掉。

## 咒語 3：卡關急救包 🚑

```text
我把你給的程式碼存成 index.html，用瀏覽器打開後【畫面一片空白 / 排版很亂 / 按鈕沒反應】。
請幫我檢查可能的原因，並給我修正後的完整程式碼。
```

```text
請用非電資背景的大學生也聽得懂的方式，解釋這段程式碼的每個區塊在做什麼。
```

## 💾 如何把 AI 給的程式碼存成 `index.html`

### 方法 A：AI 有提供下載按鈕（最簡單）
- Claude：在 Artifact 預覽視窗右上角，選擇「Download」。
- ChatGPT／Gemini：在 Canvas 視窗中尋找下載或匯出選項。
- 下載後請**確認檔名是 `index.html`**，不是就重新命名。

### 方法 B：複製貼上到記事本

**Windows：**
1. 在 AI 程式碼區塊右上角按「Copy（複製）」。
2. 打開「記事本（Notepad）」，貼上。
3. 「檔案」→「另存新檔」。
4. **存檔類型選「所有檔案 (\*.\*)」**，檔名輸入 `index.html`，編碼選 **UTF-8**。
5. 儲存到桌面。

**macOS：**
1. 複製程式碼。
2. 打開「文字編輯（TextEdit）」，先按選單「格式」→「製作純文字」（⇧⌘T）。
3. 貼上，儲存時檔名輸入 `index.html`，編碼選 **UTF-8**。
4. 若跳出「使用 .html 嗎？」請選「使用 .html」。

> ⚠️ **最常見的錯誤**：檔名變成 `index.html.txt`！
> - Windows：打開檔案總管 →「檢視」→ 勾選「副檔名」，就能看到真正的檔名。
> - macOS：Finder →「設定」→「進階」→ 勾選「顯示所有檔案副檔名」。

### 方法 C：想用專業工具？（選做）
- [VS Code](https://code.visualstudio.com/)：工程師最常用的免費編輯器。
- [VS Code 官方入門影片](https://code.visualstudio.com/docs/getstarted/introvideos)
